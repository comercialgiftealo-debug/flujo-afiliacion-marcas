Coordinar capacitación con el comercio
→ Equipo interno / Operaciones
  • Realizar la sesión de capacitación
  • Al cierre: enviar correo con el speech de cierre al comercio
  • Adjuntar: Capacitación Valid Code, Proceso contable, Credenciales

💡
¿Por qué en paralelo?
Se necesitan las credenciales de Valid Code para dar acceso a la marca. Estas dependen del código cliente (Contabilidad). Mientras se tramitan los documentos y el arte, se puede avanzar la capacitación para no perder tiempo.
